What is Lapo?

Lapo is a private, single-user AI assistant that automates everyday tasks — email triage, calendar management, payments, research, and more — on behalf of one person.

Private by design

This application is not a public service. It is a personal automation tool used exclusively by its owner. No data is shared with third parties, sold, or used for any purpose beyond the owner's personal task automation.

Google API usage

Lapo uses the Google API to read and manage Gmail, Calendar, and Drive on behalf of the single authorized user. This access is used solely to automate personal tasks and is never used to collect, analyze, or distribute data to anyone else.
